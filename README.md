# MECHONANCE 2.0 2K26 website

A mobile-first static website inspired by the supplied ECLECTICA screenshots: dark navy background, cyan/gold accents, glowing technical atmosphere, hero emblem, event cards, countdown panel, team cards and registration section.

## Files
- `index.html` — all page content and sections
- `style.css` — responsive styling and visual effects
- `script.js` — mobile navigation

## Important before publishing
This is a close visual recreation of the supplied screenshots, not a copy of ECLECTICA's source code. Mechanical Department branding and sample event names are used. The screenshots do not provide official MECHONANCE dates, HOD/faculty/student names, event rules, prize amounts, venue details or registration URLs. Replace all sample/placeholder information with department-approved details.

The registration button currently opens an email enquiry using `mechanical@mits.ac.in`; confirm the correct official contact address before launch.

## Preview
Open `index.html` in a browser. For hosting, upload the three website files to a static host such as Vercel, Netlify or GitHub Pages.
